# C04 定位板、开关底部避空和垫片安装

当前 Raytac 候选方案采用此机械修订。保留 FELK60 原外形、上壳、键位中心、卫星轴开孔和实际使用的 28 处安装位置。定位板**外周向内收 0.40 mm**，内部开孔不变。距开孔的最窄名义金属边宽为 1.7498 mm，尚未扣除切割公差，也不等于强度验收；底壳另加内部凹槽，为 SW100 留出间隙。

在下列尺寸限值内，**定位板和开关**的有界几何检查通过。整键盘适配、泡棉性能、带线插头检修路径和实物电气功能仍待验收。这里的限值是成品需要测量满足的要求，不是对任意树脂打印或供应商元件的保证。

候选板使用此 C04 DXF 代替原定位板外周；发送**完整 DXF**，保留全部开孔。这是钢板，不是额外 PCB。[当前 PCB 制板包](FIRST-ARTICLE.zh-CN.md)沿用。NiZ、卫星轴、键帽和紧固件采购要求沿用，H26 仍不安装；不要移动轴体或另钻 PCB 卫星轴孔。

DXF 中 28 个圆为 **Ø1.623 mm 的 M2 × 0.4 螺纹加工基准**，不是最终通孔交货要求。下单应包含切割**和攻丝**，由加工方选择合适的底孔／精加工方式。支柱上端 1.0 mm 长的 M2 螺柱旋入这些定位板螺纹，不使用上方螺母；只激光切完底孔的板不能按此方式装配。接近电子件之前完成攻丝、清洗和去毛刺，详见[既有紧固件／定位板加工说明](../../docs/build/key-mechanism.zh-CN.md)。

## 尺寸接收限值

| 项目 | 限值 |
|---|---|
| 定位板外周轮廓误差 | 每点 XY 径向 ≤0.10 mm |
| 定位板安装 XY 位置误差 | 每点径向 ≤0.10 mm，平移、转动和变形合并计算 |
| 定位板安装表面 Z 误差 | 上下两个表面均 ≤0.10 mm，包含实际板厚、垫片调整和变形的合并影响 |
| 外壳成品坐标误差 | 每个坐标轴 ≤0.15 mm，计算保守采用 0.259808 mm 空间误差上限 |
| 主板成品厚度 | 1.44～1.76 mm，沿用普通 JLC 接收范围 |
| PCB 安装 XY 位置误差 | 每个轴 ≤0.25 mm，包含相对定位板的安装偏差 |
| SW100 安装高度 | 距局部 PCB 背面向下 ≤3.60 mm，包含焊接和拨柄 |
| SW100 额外 XY 包络误差 | 相对已声明的装配院落包络，每个轴 ≤0.10 mm |
| SW100 处额外安装后 PCB 下翘 | ≤0.15 mm，在紧固后测量，与板厚、支柱／绝缘片变化分别计入 |
| 垫片切割与安装 XY 误差 | 每个轴合计 ≤0.15 mm |

开关高度属于项目成品检查包络，不能仅凭原厂标称图认定安装高度合格。PCB 自由状态的翘曲指标也不能证明安装后的下翘满足这一限值。

## 计算及证据

检查器将实际 C04 外轮廓在 XY 向外扩 **0.10＋0.10＝0.20 mm**，在 Z 向上下各扩 **0.10 mm**。实体保守包含内部开孔空间，覆盖所有允许的中间点；底壳取出检查把这一完整包络沿 **22 mm** 行程拉伸。XY 圆形扩张采用外包处理，避免多边形圆弧近似漏掉误差范围。

各项采用 `剩余间隙＝包络至外壳距离－sqrt(3)×0.15－0.002 mm`。最后一项是数值／几何余量，要求至少剩 **0.15 mm**。这是最坏情况算术界限，不是统计平均。定位板计入这些误差后约剩 **0.188 mm**。

开关包络包含普通 PCB 向下增厚 `1.76－1.6062＝0.1538 mm`、支柱 0.03、绝缘片 0.02、定位板安装 Z 0.10、安装后下翘 0.15，以及安装高度增加 `3.60－3.50＝0.10 mm`；XY 同时计入 PCB 定位与开关贴装。凹槽范围为 X **104.975～119.025**、Y **−127.525～−114.725**、Z **−6.71～−5.40 mm**，圆角半径 0.5 mm。保留原外部操作孔和原外形；余壁与螺丝／嵌件支撑检查已纳入新增切除区域。

## 八条垫片的安装

上下两层均使用以下壳体坐标中心；长边沿 X 方向：

| 位置 | X／mm | Y／mm |
|---|---:|---:|
| 前左 | 102.5877 | −201.7000 |
| 前右 | 326.5877 | −201.7000 |
| 后左 | 128.5877 | −100.2500 |
| 后右 | 300.0877 | −100.2500 |

检查器确认，在给定 XY 误差内，八条垫片仍完整落在壳体承托面和定位板金属上。下层贴在四处底壳承托台阶，上层贴在对应的四处上壳承托面。胶层不得超出占用范围，其厚度须纳入堆叠测量。垫片不能跨轴孔或螺孔。

实际测量外壳承托高度、泡棉／胶层厚度及定位板安装表面。在给定外壳和定位板 Z 限值内，下层几何间距可能约为 **0.7662～1.2662 mm**，上层约为 **0.3338～0.8338 mm**。指定原料厚度是名义起点；这些间距**没有**证明任意泡棉的压缩力、蠕变或胶粘性能合格。首件需验证合适的材料／压缩量，必要时调整实测垫片厚度，并保持定位板安装限值；不要靠强行关壳获得名义高度。

材料研究：[Rogers 原厂可供货手册](https://www.rogerscorp.com/-/media/project/rogerscorp/documents/elastomeric-material-solutions/poron/english/product-availability/17-082-poron-polyurethanes-product-availability-brochure.pdf)中，同属 PORON 4701-30 的厚度和密度也不同。例如带支撑层的 `4701-30-25047-04 P` 为 1.19 mm／400 kg/m³，`4701-30-20064-04 P` 为 1.63 mm／320 kg/m³。商品写“PORON 1.2 mm”不能证明材料或压缩力相同。[原厂数据表](https://rogerscorp.com/-/media/project/rogerscorp/documents/elastomeric-material-solutions/poron/english/data-sheets/17-006-poron-4701-30-very-soft.pdf)的压缩力测试对应 25% 变形，不能直接当作 50～75% 压缩时的力。这些只是参考候选，尚未冻结垫片型号；泡棉验收前需拿到实际牌号、含支撑／胶层的总厚度和完整压缩曲线。


当前[完整爆炸图](assembly/exploded.png)包含八条分开的安装垫片。按[候选板装配顺序](ASSEMBLY.zh-CN.md)操作，以本定位板和本垫片代替原外周／原料托盘示意。

按键操作和搬动后，也必须保持规定的安装位置限值。几何证明没有证明垫片摩擦或胶层能保持该位置；居中安装和位置保持力仍需验收。
