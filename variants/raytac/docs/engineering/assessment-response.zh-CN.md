# 对 P2 可行性评估的回应

保留[2026-10-28 评估](../audit/2026-10-28-feasibility-assessment.zh-CN.md)作为当时的审查记录。本文件记录后续决定与验收事项。用户新增的 **仅使用 JLC 普通工艺**要求优先于其中的 HDI 采购路线。继续使用 C5 JSH、单 nRF52840 和定制 1600 mAh 单电芯；信号及射频干扰分析暂缓。

| 评估问题 | 回应或调整 | 仍需取得的验收证据 |
|---|---|---|
| 单主控架构 | 保留，由 nRF52840 完成扫描及 USB／蓝牙 | 实机枚举、配对、逐键校准及恢复测试 |
| A1：充电电流余量窄 | R40 保持 2.21k／1%；将 450 mA 编程工程上限与新增的至少 500 mA 电池包连续充电额定要求分开 | 供方修正矛盾的电流数据，签署额定值和充电温区 |
| A1：终止电流余量窄 | R56 从 1.82k 改为 1.69k／1%；最大值由 31.51 降至 29.26 mA，相对暂定 32 mA 终点余量由 0.49 增至 2.74 mA | 完整恒流／恒压充电与计时测试；更低终止电流可能延长恒压时间 |
| A1：充电稳压与温度保护 | 电池规格新增整个 4.16–4.23 V 稳压范围的接受要求、独立温度断充及单独的 NTC 反馈 | 更正后的电芯限值、完整包图、保护与充电实测；仅有温度引线不能关闭此问题 |
| A2：特殊制板依赖 | 改走普通通孔和 JLC 普通四层叠层；不得依赖盲埋孔、激光孔或填孔盖铜 | 普通工艺检查、原生设计规则及导通检查、JLC 文件审查；旧 HDI 包不可下单 |
| A3：静电容结构未冻结 | 取消“原装 HHKB 可拆轴座”假设，要求配套的独立安装部件，先验收普通键／宽键／6U 空格局部样件 | 实际供方零件、完整行程与回弹、胶碗预压、稳定机构／键帽和螺纹寿命 |
| A4：阻容、保险丝、LED 未选定 | README 列齐所有实装位号、数值、封装与选型状态，保留待选标识 | 精确型号、电容有效容量、保险丝降额、LED 电流及压降；标称容量不足以验收 |
| B：线束未验收 | 增加完整插壳包络、七根连续实体导线、静态弯曲半径及可拆固定座，并接入审计与渲染来源检查 | 实际线径／长度／出线高度、回弹、压接、插拔与绝缘磨损 |
| B：紧固件与电池公差窄 | 保留安装中心，明确普通板厚、垫片／头部及树脂公差 | 来料尺寸检查及局部机械样件；不能静默放过负间隙 |
| C：功耗模型有假设 | 保留空闲扫描、模拟前端门控和稳压器直流转换；106.64 小时仍按模拟前端常开保守估算，不虚构节电收益 | 电池侧电流记录、空闲占空比、首键延迟、容量与续航测试 |
| 充电及使用行为 | 保留主机配置后 USB500、关机 USB100 和关机漏电说明 | 两种充电状态及仅充电适配器行为的实机测试 |

## 工程样机阶段门槛

| 阶段 | 准备内容 | 必须记录的通过条件 |
|---|---|---|
| S0 电源与固件治具 | 1 块普通工艺主板，限流 USB 源与电池模拟器；先不用未验收电池 | 电压与极性正确、无短路、可刷写、USB 状态正确、前端门控、稳压瞬态及充电控制；保存示波器、电流和温度记录 |
| S1 局部按键结构 | 普通键、宽开孔、6U 空格结构和代表性支柱样件；使用实际配套轴座／胶碗／弹簧／键帽 | 全行程、回弹、无干涉、预压、螺纹啮合及反复拆装合格；取得静电容按下／释放分布 |
| S2 完整工程样机 | S0／S1 和电池供方验收后制作 3 把 | 全部实装键校准、空位不误触、USB／蓝牙恢复、控制路径装线、充电终止与温升／续航测试 |
| S3 小批试产 | S2 留存记录通过并冻结物料及制板工艺后，再考虑 10–30 把 | 良率、一致性、机械寿命及供方稳定性；不会自动获得量产放行 |

供方及实测门槛是明确保留的限制，不是已经完成的测试。[当前审计结果](../audit/outcome.json)记录实际通过的软件与 CAD 检查。[制板交付](fabrication-review.zh-CN.md)、[电池包规格](battery-pack-specification.zh-CN.md)与[材料清单](materials.zh-CN.md)将后续请求具体化；本流程没有联系厂商或下单。
