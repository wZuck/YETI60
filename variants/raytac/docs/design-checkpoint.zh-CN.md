# P2 阶段设计记录

本阶段为工程样机设计，尚非制造发布。目前没有实物，用户授权的里程碑是完成设计和可构建固件；静电容实机校准与制造验收在取得样品后进行。

- **子板：**保留 Unified Daughterboard **C5 JSH**，锁定 `2b6c52a`，保留四个 M2 安装位置和 J1 的 VBUS／D−／D+／GND 线序，不替换为 UDB S。
- **电池：**默认定制 **1600 mAh**，完整包络 **85×43×4.8 mm**，以 HCP404074 为参考。在明确的 651 型号、1 mm 网格条件中，它是找到的最大候选。选定包络精确检查无碰撞，到螺钉头名义间隙 0.70 mm，扣除 0.30 mm 后最小壁厚 3.6585 mm。正式底壳包含凹槽，FELK60 外部联合包围尺寸仍为 325.700×125.200×31.190 mm。
- **电源：**保留 BQ24074；R40=2.21k、R55=69.8k、R56=1.69k，均为 1%。充电设定最小／典型／最大为 357.06／402.71／445.63 mA；快充计时为 6.9102／9.3067／11.7497 小时；最大终止电流 29.26 mA。这些计算不证明能完整充满。定制包必须有独立温度断充，实际电芯充电窗口在 15…43°C 内，另带 NTC，并由供方签署保护和尺寸图。原厂电流行存在矛盾，下单前须更正确认。
- **PCB：**JLC 普通四层 FR-4、JLC04161H-7628、标称 1.6 mm（CAD 包络 1.6062 mm）。没有盲埋孔、激光孔或模组盘中孔，不要求填孔盖铜；电极铜形状、板框和安装中心保留，感应介质为 0.2104 mm，仍需实物校准。当前文件以原生规则、网表及 270 对实际引脚检查为准。
- **固件：**普通版及 USB 串口校准版 ARM ELF／HEX 已由完全锁定的 ZMK／Zephyr 依赖构建；两个链接产物的 USB 描述符均申请 500 mA。只有主机接受配置后才允许 USB500 充电；挂起禁充，恢复保留已接受配置。HEX 检查保护设置分区。USB／BLE HID、配对及主机切换由 ZMK 提供，实机行为未测试。
- **证据：**当前工程图、PCB 图／动画和摄影风格装配渲染都有来源与产物清单。电池、键帽、轴座及材质仍有设计包络或示意部分。[工程证据](audit/yeti60-engineering.json)和[集成检查](audit/integration.json)须匹配当前哈希。

[功耗模型](engineering/power-budget.zh-CN.md)在规划假设下为 106.64 小时，非实测续航。供方电池／电流／温度保护批准、完整线束和插头可维修性、实际轴座胶碗、普通制板验收和器件额定值、树脂嵌件强度，以及首件装配／充电仍须验收。信号干扰分析按用户要求延后。当前方案见[材料表](engineering/materials.zh-CN.md)、[装配](engineering/assembly.zh-CN.md)和[电池选型](engineering/battery-study.zh-CN.md)；完整复查记录当前检查和验收边界。
