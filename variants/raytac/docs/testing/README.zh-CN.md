## 首件按以下顺序记录

1. **收板和断电检查：**量板厚、板框和 29 个孔，检查电极、方向、焊接和隐藏焊点；用万用表核对供电、线束通断和每个连接器针序。检查失败先返修，不接电池。
2. **电源与刷写：**使用限流 USB 源和电池模拟器，确认电源轨、无异常热点与电流，再 SWD 编程／校验；不用真实软包做反接、短路或过温试验。见[接线与刷写命令](../build/flashing.zh-CN.md)。
3. **局部结构：**先试普通键、宽键和 6U 空格；确认独立轴座、胶碗预压、弹簧位置、全行程／回弹及稳定机构。验证支柱与隔离垫，不能靠拧紧螺钉消除干涉。
4. **逐键校准：**装好真实机构后执行 release、逐键持按 press、status、save；全部 60 键满足保护区间、无饱和／重叠才通过。不用安静环境的一次校准掩盖充电或蓝牙时的误触。
5. **USB 与蓝牙：**在真实电脑上确认枚举和 HID；电脑接受配置后，同时记录电池侧正向充电电流与 USB 按键报告。检查历史蓝牙偏好不会阻止 USB 自动优先，拔线、重插、复位、挂起、恢复和蓝牙重连均正常。
6. **充电与温度：**配置前和固件运行时挂起不充电；USB500 为输入预算，不是固定电池电流。SW100 关闭时另验 USB100 自主慢充；普通充电器不枚举，不能当作数据主机。只有供方签收的完整保护包才能做真实充电、终止、独立温度断充及续航测试。温度反馈替代等操作由合格台架人员实施，不加热真实软包强迫触发。
7. **最终合壳：**复查 PCB 居中、射频凹槽、线束压接／弯曲／插拔、支架、螺钉啮合和电池不受压；检查各项公差，再合壳重做 60 键、USB／BLE、充电和温升测试。
8. **射频和电容干扰：**在实际树脂外壳、最终电池与键帽下测距离、方向、丢包／重连，以及空闲、按键、USB 输入、充电、BLE 发射时各键的松键／按键分布。未测的项目记为未测，不记为通过；需要的 USB／EMC／ESD 合规测试由有能力的实验室完成。

保留板号、PCB／固件哈希、实际物料和电池批次、仪器设置、日志、波形、温度、照片与每项通过／失败结果。首件通过后才能评估扩大数量，不能把 CAD 一致性结论当成量产批准。
