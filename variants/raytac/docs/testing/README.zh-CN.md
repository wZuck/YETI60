## 首件按以下顺序记录

1. **收板和断电检查：**量板厚、板框和 29 个孔，检查电极、方向、焊接和隐藏焊点；用万用表核对供电、线束通断和每个连接器针序。检查失败先返修，不接电池。
2. **电源与刷写：**使用限流 USB 源和电池模拟器，确认电源轨、无异常热点与电流，再 SWD 编程／校验；不用真实软包做反接、短路或过温试验。见[接线与刷写命令](../build/flashing.zh-CN.md)。
3. **局部结构：**先试普通键、宽键和 6U 空格；确认独立轴座、胶碗预压、弹簧位置、全行程／回弹及稳定机构。验证支柱与隔离垫，不能靠拧紧螺钉消除干涉。
4. **逐键校准：**装好真实机构后执行 release、逐键持按 press、status、save；全部 60 键满足保护区间、无饱和／重叠才通过。不用安静环境的一次校准掩盖充电或蓝牙时的误触。
5. **USB 与蓝牙：**在真实电脑上确认枚举和 HID；电脑接受配置后，同时记录电池侧正向充电电流与 USB 按键报告。检查历史蓝牙偏好不会阻止 USB 自动优先，拔线、重插、复位、挂起、恢复和蓝牙重连均正常。
6. **充电与温度：**配置前和固件运行时挂起不充电；USB500 为输入预算，不是固定电池电流。SW100 关闭时另验 USB100 自主慢充；普通充电器不枚举，不能当作数据主机。只有供方签收的完整保护包才能做真实充电、终止、独立温度断充及续航测试。温度反馈替代等操作由合格台架人员实施，不加热真实软包强迫触发。
7. **最终合壳：**复查 PCB 居中、射频凹槽、线束压接／弯曲／插拔、支架、螺钉啮合和电池不受压；检查各项公差，再合壳重做 60 键、USB／BLE、充电和温升测试。
8. **射频和电容干扰：**在实际树脂外壳、最终电池与键帽下测距离、方向、丢包／重连，以及空闲、按键、USB 输入、充电、BLE 发射时各键的松键／按键分布。未测的项目记为未测，不记为通过；需要的 USB／EMC／ESD 合规测试由有能力的实验室完成。

保留板号、PCB／固件哈希、实际物料和电池批次、仪器设置、日志、波形、温度、照片与每项通过／失败结果。首件通过后才能评估扩大数量，不能把 CAD 一致性结论当成量产批准。

机械验收按 [NiZ 钢板卫星轴指南](../build/key-mechanism.zh-CN.md)：28 套紧固件、H26 留空、下／上胶棉 2.0／1.2 mm；核对 NiZ 卡扣下缘、三组独立卫星轴、实际 6U 钢丝键帽配合、松键回弹及完整行程，按大键时同时检查附近未按的静电容按键。

新增[模拟 GPIO／初始化清理检查](gpio-mode-policy.zh-CN.md)覆盖实际回调、初始化函数、固定 Zephyr 标志以及关轨结束状态；实际漏电和电源下降仍须测量。

扫描初始化失败时命令立即返回不可用；运行故障关闭模拟前端、释放已记录按键并拒绝继续采集／保存。两个固件均采用 128 项按键事件队列。见[扫描状态与故障回归](scan-control.zh-CN.md)，包含实际工作循环、60 键采集和 120 事件突发测试；真实主机送达仍待首板验收。

校准记录现为带独立 CRC-32 的 308 字节，旧 304 字节记录必须重新采集；全局 NVS 设置格式及蓝牙绑定不变。见[校准存储校验与升级](calibration-storage.zh-CN.md)。损坏注入已覆盖，真实闪存断电仍待首板验收。

新增[固定版本 NVS 中断恢复模型](nvs-powercut.zh-CN.md)：实际 NVS／校准加载代码完成 14,795 次指定中断试验，覆盖垃圾回收和恢复期间再次中断；哨兵及恢复后再次保存均通过。它不是物理 NVMC／欠压／蓝牙验收。NVS 模型本身只增加测试；已有候选产物可用 `--host-tests-only` 重新验证并发布测试，来源变动则必须完整构建。

[矩阵、Fn 与 HID 链路](key-pipeline.zh-CN.md)执行固定版本 ZMK 的实际转换、层选择和 HID 代码。当前为六个普通键的 HID 槽位，修饰键另算；60 键扫描不等于全键无冲。六组场景及四个错误变体验证通过，真实主机和传输仍待验收。

[实际 ELF 的 HID 格式核对](key-pipeline.zh-CN.md#已链接的-usb蓝牙报告格式)确认 USB 报告 9／13 字节匹配 16 字节端点，蓝牙报告体为 8／12 字节；两份映射及 Report Reference 一致。运行时描述符填充、枚举和主机收包仍待实测。

[电源状态审查](../engineering/power-states.zh-CN.md)区分主控复位、USB 总线复位和关机。首板增加启动默认充电、挂起时电池支撑消失及真实关机电流捕获；保护包仍须独立验收。
