# 当前 PCB 的特殊制板要求

主控 U1 保持在原位置。U1.39（ROW_DRV2，343.25 / 120.35 mm）和 U1.51（SWDIO，348.85 / 120.35 mm）各使用一个外径 0.50 mm、钻孔 0.30 mm 的通孔，位于模块焊盘内。

**这两个孔必须树脂填孔、磨平并盖铜，保持可贴装的平整焊盘表面。不能用普通开孔或仅盖油代替。** 下单时应将此要求交给 PCB 厂和贴片厂确认；几何 DRC 不会验证实际填孔盖铜工艺。

U5 的接地／散热焊盘另有接地过孔，需结合焊膏开窗控制吸锡。该处与主控两个信号焊盘内过孔分别审核。

当前 CAD 检查不代替样板上电、充电温升、稳压器稳定性、电容有效容量、USB 子板和外壳实装验证。射频与信号干扰分析按要求暂未进行。

## 背面 HDI 电源布线

U6／C45／C46、U5／C40／C41 及 P2 的 ITERM／R56 路径共九个微盲孔连接 B.Cu 与 In2.Cu，**铜盘直径 0.40 mm、激光孔径 0.20 mm，须填充整平**。不能加工为通孔。名义叠层依次为：正面阻焊 0.010、F.Cu 0.035、上介质 0.200、In1.Cu 0.0175、芯板 1.115、In2.Cu 0.0175、下层激光介质 0.150、B.Cu 0.035、背面阻焊 0.010 mm，成品包络为 1.590 mm。保持上层感应介质厚度，表面采用化金。下层激光介质及孔深径比、填孔、整平、介质公差和成品翘曲须由板厂确认。不可替换回原对称叠层或开放微盲孔。
