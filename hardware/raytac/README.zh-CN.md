# Raytac 当前候选板下载

本目录只提供当前修补候选板的原生 PCB、主板 Gerber／钻孔包及背面钢网副本，均与[首板入口](../../variants/raytac/hardware/usb-short-route/FIRST-ARTICLE.zh-CN.md)来源一致；用[哈希清单](manifest.json)确认版本。旧布线的重复下载包已移除，历史参考仍保留在方案目录中。

从[首板入口](../../variants/raytac/hardware/usb-short-route/FIRST-ARTICLE.zh-CN.md)查阅 JLC 参数、备料、接线和无外壳验证。编辑工程或查看模型／封装库时使用方案目录的完整工程，不把本目录的单个 PCB 副本当作完整工程。生产前仍需板厂 DFM；实物验收和生产批准尚未完成。
