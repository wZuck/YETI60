# CORNER-07 首件验收

从裸主板和已经制作的 C5 子板开始，壳外即可完成台架阶段。最初充电测试使用电池模拟器。之后的步骤使用 NiZ 机构、符合规格的保护电池包及合壳样机。

每台样机复制一份本页。记录交付清单中的 PCB 和固件摘要、板材实测厚度、C5 版本、电池包编号、环境温度、主机、USB 线和仪器。逐项填写测量结果。设计报告的检查结果与实测结果分别记录。

| 阶段 | 验收动作和记录 | 通过条件 |
|---|---|---|
| 工厂制造预览 | 将预览和工厂叠层报价与[下单说明](../01-pcb/ordering-and-printing.zh-CN.md)比对。核对非金属化孔、槽、双面钢网、C42、C48、D2 孔位及 C42、SW1、U5、U6 开窗对位 | 工厂确认普通四层工艺和提交的几何。工厂如提出修改，确认后记录 |
| 裸板 | 检查焊点和极性，按顺序限流上电。确认 3.3 V 和 J3 针序 | 无短路、异常电流或发热。电源轨及 SWD 识别正确。[焊接步骤](../04-assembly/soldering.zh-CN.md) |
| 壳外刷写 | 电池断开时通过 SWD 刷校准固件。核对 C5 线束针序，检查 USB 枚举 | 烧录器校验通过。电脑识别设备且连接稳定。[固件和 J3 针序](../05-firmware/installation.zh-CN.md) |
| 电池模拟器 | 测 USB 配置前后、弱供电、挂起、恢复及关机 USB100 时，充电器 IN、OUT、BAT、电流和 E73 VBUS。按需对比实际线材 | 充电状态符合说明。整机通过 100／500 mA 和插入浪涌检查。降流期间仍走 USB HID，U1 VBUS 在 USB 工作时满足规格，输入字符无丢失且无复位。[台架接法和测点](bench-power.zh-CN.md) |
| 全键 | 在壳外装定位板、胶碗和弹簧。保存全部 60 键的校准值，再保留设置刷正常版。逐键测试按下、释放，以及三个卫星轴大键的两侧 | 60 个位置均触发预期键值或层功能。大键两侧均能回弹且不卡滞。[机构指南](../04-assembly/key-mechanism.zh-CN.md) |
| 实物电池 | 核对供应商图纸、电流、极性、热敏电阻和独立过温／低温断充。模拟器通过后再实测充电电流、终止、温度及关机电流 | 符合供应商确认的[完整保护包要求](../03-bom/battery-requirements.zh-CN.md)，包括独立断充及正常充满所需时间 |
| M05 试装和拆开 | 记录实际 PCB 厚度及两只盖的坐合情况。按 [M05 首件指南](../02-mechanical/service-case-m05/print-guide.zh-CN.md) 暂装配套线束和理线件，使用无电量块、两把工具和两套停放支撑。依次拔开 J2、J4，验证 25 mm 垂直抬板，反向复装 | 无强压、夹线、触点损伤、插头松动或量块受压。记录实际夹持、走线和重复装拆情况 |
| 关壳 | 空闲、充电和拔线后分别测试 USB 及蓝牙输入。用实际手位和方向测试 2 米、3 米。测充电器及电池温度，同时记录充电和发射时是否漏键、误触或连发 | 在记录的时长及条件下满足使用距离和温度要求，无异常键盘事件、断线或发热 |

出现失败时先记录并整改，再按对应条件复测。所有使用条件相关项目通过后再验收整机。
