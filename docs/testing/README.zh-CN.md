# YETI60 验收与测试流程

[修补方案与关闭证据](remediation-plan.zh-CN.md) · [新版逐键校准](calibration.zh-CN.md)

**当前设计验收暂不通过。**两套方案可构建，已实现的电气／CAD 检查通过，但本次干扰检查发现天线布局风险：Raytac 厂商最小天线投影区内有接地铜；E73 的暂定天线端检查区有铜，且缺少厂商认可的数字净空要求。两版附近均有金属定位板投影。详见[干扰结果、计算和来源](interference.zh-CN.md)。目前没有实物，以下实测项目均不能算通过。

装配、刷写和测试全过程选择同一套完整方案：

|---|---|---|
| 默认 E73-2G4M08S1C | [28 步逐步图解](../assembly/build-guide.zh-CN.md) | [HEX、刷写和校准流程](../../firmware/target/README.zh-CN.md) |

E73 有五个已连接的底部焊盘，需要回流；边缘焊盘外露不代表整板可只用烙铁完成。两版还都有隐藏焊盘电源封装，装配前须确认钢网、锡膏和工艺。两套主板的光绘、模组、引脚合同和固件不能混用；共用 C5 JSH 和外壳。只有自行焊接 C5 时才执行可选的子板裸板步骤。

## 已执行的设计检查

[当前验收记录](../audit/acceptance.json)区分“测试执行成功”和“产品通过验收”，记录输入／输出哈希、两版完整审计、四个 ARM 目标、主机模拟、射频／USB 初筛、TI OPA350 仿真和有条件的壳体／定位板匹配检查。[两版合并记录](../audit/variants.json)确认方案处于同一分支。

| 验收门槛 | 当前证据 | 含义 |
|---|---|---|
| 连通性／JLC 普通工艺 | 每版严格原生 DRC：0 错误、0 未连接、270 组物理信号引脚 | CAD 通过；仍公开保留 E73 114 项／Raytac 108 项警告 |
| 固件 | 每版普通／校准 ARM ELF、BIN、HEX；主机 ASan/UBSan 测试 | 构建和可移植核心通过；主机测试中的 GPIO、ADC、USB、BLE 为替身 |
| 噪声逻辑 | 每版 2000 帧迟滞区噪声，加 2000 帧相关纹波／孤立突发 | 消抖行为符合预期；连续两帧越过阈值仍会产生模拟误键 |
| 模拟前端 | 固定哈希的 TI 官方 OPA350 模型；28 组敏感性工况 | 交流／瞬态模型检查通过；实物噪声裕量未知 |

| 装配 | 60 键、29 安装孔、原尺寸外壳；当前器件／电池／线束包络 | 仅有条件 CAD 匹配；实际胶碗压缩、供方电池、树脂和紧固件仍未验收 |

## 复现检查

在仓库根目录执行。CAD 环境满足 [requirements-audit.txt](../../requirements-audit.txt)，另外需要 KiCad Python 和 `ngspice`。可通过 `KICAD_PYTHON`、`YETI_CAD_PYTHON` 指定已安装环境。TI 模型下载至忽略的本地目录，以固定 SHA-256 核验，不随仓库再分发。

```sh
python3 scripts/run_acceptance.py --refresh-guide
python3 scripts/check_yeti60_acceptance.py
```

第一条命令重跑两版完整审计，按选项重建指南，执行原生布局、SPICE、定位板检查及反例测试，再生成验收证据。退出码 0 只表示检查执行完毕、证据一致，其中可以包含已记录的失败／未关闭门槛，**不代表键盘验收通过**。执行 `python3 scripts/check_yeti60_acceptance.py --require-accepted`，验收阻塞时返回 2；缺依赖、证据过期或测试执行失败返回非零。现有三维渲染按哈希检查；PCB／外壳变更后须按原有流程重新生成。

## 首件顺序

每块板的序列号和固件版本各复制一份[测量模板](first-article-template.csv)，保留原模板未填写。下列数值是项目验收目标，不是蓝牙、USB 或电磁兼容认证限值。每项保存仪器设置、照片、日志和原始波形，不能根据图纸或构建结果填写“通过”。

| 顺序／指南步骤 | 操作及仪器 | 项目通过条件 |
|---|---|---|
| 1／01–03 | 板型／模组／材料识别，显微镜，断电裸板导通检查 | 方案正确，无桥连、反装、短路；检查所有必要焊盘。E73 底部及电源散热焊点采用 X 光或装配商已验证的隐藏焊点检查 |
| 2／04–11、14–16 | 分电源域装配；首次上电前检查极性和阻值；限流台式电源，不接电池 | 从 50 mA 台式限流开始，出现限流先排查；确认合理负载后才提高。3.3 V 电源满足项目 ±5%，无异常发热、持续限流或失稳；记录启动及负载瞬态，不能只看万用表 |
| 3／12–17 | C5 两路 CC 电阻、线束逐针导通／绝缘、实物插头匹配 | 两路各自 5.1 kΩ；D+／D−／VBUS／GND 正确，无交叉线及软包受力；按图核对最终走线和可维修性 |
| 4／18–20 | SWD 刷正确校准 HEX、回读校验、抓 USB 描述符和采样日志 | 引脚映射正确，E73 按需设置 UICR 的 NFC 引脚为 GPIO；识别 60 个实际键位，无 ADC 饱和／缺通道 |
| 5／21–25 | 实际轴壳、胶碗、弹簧、隔柱、薄膜、紧固件、保护电池干装 | 29 孔对齐，PCB 不弯、合壳无需强压，开关可操作，电池不受压，嵌件牢固；记录实际堆叠和供体零件；定制 1600 mAh 电池仍须供方验收 |
| 6／26–27 | 逐键校准及[干扰矩阵](interference.zh-CN.md#实物干扰矩阵) | 所有模式下松开／按下分布具有正的带保护裕量；指定运行中零误键／漏键／卡键；保留原始采样及阈值 |
| 7／27 | USB 分析仪、电池侧电流记录仪、热电偶；由合格台架操作者替代温度传感器输入 | 配置前／挂起／关机遵守 USB100，主机完成配置后才启用 USB500；充电电流、终止、电源限值和独立 15–43°C 中断满足[电源](../engineering/power-budget.zh-CN.md)与[电池规格](../engineering/battery-pack-specification.zh-CN.md)。不能通过加热／冷冻／短接软包强造故障 |
| 8／27 | USB 插拔、挂起／恢复各 100 次；蓝牙连接／重连／切换配置 100 次；主机 HID 日志 | 无卡键、丢失状态、枚举失败、意外重启或未处理报告丢失；五配置绑定符合预期，在计划使用的主机系统上验证 |
| 9／28 | 普通固件，断开调试器；记录打字、空闲、广播、重连、关机和完整可用放电 | 记录实测电流、可用容量，并与模型核对续航；不得把预测小时数记作实测值 |

发布前关闭天线布局问题并重跑所有受影响项目。所需的辐射／传导发射、抗扰和静电认证由合格实验室执行，本仓库不宣称获得认证。
