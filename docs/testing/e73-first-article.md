# CORNER-07 first article

Start with the bare board and the already-made C5 daughterboard. The bench stages do not require a case. Use a battery simulator for the first charging tests. The later stages require the NiZ mechanism, the specified pack and the closed case.

Copy this page for each unit. Record the PCB and firmware digests from the delivery manifest, the actual PCB thickness, the C5 revision, the pack identifier, ambient temperature, host, cable and instruments. Record measurements beside each result. A checked design report cannot populate a physical result.

## Key-by-key record

Copy the [key acceptance CSV](../../delivery/YETI60-E73/06-validation/key-acceptance.csv) for each unit. Position, row/column and electrode IDs come from the current assembly drawing. Expected HID usages come from the compiled maps shared by the matching normal and calibrator builds. Each `not-run` cell starts unmeasured. Test with the normal build after saving calibration for all 60 keys. Record the observed result and trace location. `0x07/0x29` gives the hexadecimal page and usage for Escape.

1. **Open bench, configured USB and charging**. Assemble the NiZ housings, plate, domes and springs. Use a battery simulator with a valid NTC setting. Confirm positive BAT current, then fill `usb_while_charging`. Log upstream C5 current and BAT current during input. [Bench connections and limits](e73-bench-power.md)
2. **USB detached, BLE on battery**. After the simulator checks pass, connect an accepted protected pack and pair a BLE host. Detach USB, confirm BLE receives input, then fill `ble_on_battery`. Reattach USB and verify that input returns to USB and positive charge current resumes. Use separate receiving endpoints or per-transport traces to identify the path. A text field shared by both transports cannot identify the source.
3. For `center`, press the middle of the cap. For `left_edge` and `right_edge`, press the respective ends of Enter, left Shift and Space. Each stroke should assert only the expected key, then clear its usage or modifier bit on release. The two ends of Space report the same usage. Fn by itself changes a layer and emits no keyboard event.
4. For `with_fn`, hold Fn, press and release the target key, then release Fn. For `release_fn_first`, hold Fn and press **1**. Release Fn before **1**. The trace must show F1 asserted and cleared with no **1** event. A subsequent tap of **1** must use the base layer. Test Bluetooth profile selection and clearing using the [firmware recovery procedure](e73-corner-firmware.md#bluetooth-profiles-and-recovery).
5. Use a trace that shows presses, releases and modifier bits. An editor cannot verify a standalone modifier. Input methods, host shortcuts and typematic repeat can also change the displayed text. Mark missing, wrong, duplicate or stuck events as failures and save the test conditions. Repeat after case closure. Save separate copies of the record for open and closed tests.

Record a failed stage before continuing. Do not qualify the finished build until the relevant failures are corrected and retested.
