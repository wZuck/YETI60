# 修补方案与验收门槛

目标先达到可制作工程首件的设计状态，再完成实测验收。脚本执行成功不等于最终验收。保留同一分支的两版方案、每板一个 nRF52840、C5 JSH、JLC 普通四层机械通孔，以及 60 个感应电极和 29 个安装孔。FELK60 外形保持原尺寸；明确记录的小型 PCB 延伸区和树脂内部避让仅为候选设计，不是已批准量产几何。

## 已检查的天线候选

[受控候选尺寸](../../mechanical/rf-remediation.json)将 E73 放到原点 (346,117)、0°，Raytac 放到 (356.25,125.25)、90°，均在元件面，天线端超出原定位板边缘。两版共用的底壳内部避让为 X355.5–364.8、Y−133–−114、Z−5.7–0.2mm，圆角 0.8mm，外形不变。

[候选执行记录](../audit/rf-remediation-candidate.json)得到模组／壳体零碰撞，天线到定位板横向间距分别 E73 4.187mm、Raytac 3.387mm；PCB 延伸区到壳体 0.5mm；计入设定的 0.15mm 壳体公差后，采样槽底最小壁厚 1.56mm，E73 最深器件距壳仍有 0.296mm。槽底检查包含 595 个位置，不能代替完整结构薄壁或树脂强度分析。E73 最后 3mm 天线区仍为暂定，因为厂商未给出数字主板净空。**这些结果只证明候选几何可行，不代表 PCB 已完成布线或射频通过。**

## 实施顺序

1. 修复校准及其验收测试，重建四个固件目标，更新两套中英文图解指南；形成证据完整的阶段提交并推送。
2. 先证明焊盘支撑和板边间距，再在两版落实天线延伸区／壳内避让，移动模组及局部旁路器件，按原普通工艺规则重布相关网络。保留原几何和确定性的改动规格用于回归。
3. 修补 USB 路径几何，复核电源／地回流；任何局部修补若引入新 DRC、断线、感应变化或机械碰撞，都不能接受。
4. 重新生成受影响的制造数据、STEP、线束图、步骤图及渲染来源；重跑两版完整审计和干扰／验收反例测试，再发布阶段提交。
5. 设计门槛和下单审查通过后才制作；取得已验收电池及供体机构，再执行[首件流程](README.zh-CN.md)和[干扰矩阵](interference.zh-CN.md#实物干扰矩阵)。实测失败保持未关闭，修复后重跑受影响项目。没有硬件或缺少供方文件不能自动算通过。

复现：`python3 scripts/test_yeti60_calibration.py`；在 CAD 环境中运行 `scripts/study_yeti60_rf_remediation.py`。当前设计和实物状态以[验收证据](../audit/acceptance.json)为准，不以本候选计划代替验收。
