# 带保护裕量的逐键校准

旧校准使用松开最小值、按下最大值，这种乐观极值可能接受正常状态已经重叠的噪声分布。现改为有标签的逐键采样和保守边界。这是固件修复，不能代替静电容实物验收。

1. 安装最终机械结构，使用计划验收的电源和保护电池，刷入对应模组的校准版；用另一套输入设备操作 USB CDC 控制台。
2. 全部松键执行 `yeti_calibrate release`，保持所有键松开，等待完整 128 帧完成提示。再次执行松键采样会清除之前全部按键采样。
3. 查所选方案 `firmware/target/calibration-keys.csv` 中的行列。**先完全按住目标键**，再执行 `yeti_calibrate press ROW COL`，把行列替换为表中十进制数值。持续按住直到提示完成 128 个采样，再松开并处理下一键，覆盖 60 个实际按键；其余 15 个原始位置刻意不启用。
4. 执行 `yeti_calibrate status`，查看每键样本数、松开／按下极值、候选阈值、保护值和有效标记，连同板序列号及 HEX 哈希保存日志。重复指定行列命令会重新采集该键，采样中途不能松开。
5. 全部有效后执行 `yeti_calibrate save`。存在无效键、采样未结束或 NVS 写入失败时，不能提示保存成功。无行列的旧 `press` 命令会被拒绝，因为无标签的整板峰值采集不能证明按下分布。
6. 在保留设置分区的前提下刷入同一块板的普通固件。校准版本绑定引脚、设备树、原生 PCB 字节及校准算法，任一变化都会使旧阈值失效，须重新校准。不同键盘之间不复制阈值。

每种状态至少 64 个有标签样本，目标固件固定采集 128 个。任何采样达到 4090 的饱和值、缺样本、跨度不足 32 码或保护后范围重叠，都会被拒绝。可移植算法限制样本数，使用 64 位方差累积和整数计算：

```text
标准差保护估算 = 向上取整平方根（向上取整的样本方差）
G = max(6×松开标准差估算, 6×按下标准差估算, 1码)
下界 = 松开最大值 + G + 1
上界 = 按下最小值 - G - 1
要求：上界 - 下界 >= 4，按下最小值 - 松开最大值 >= 32
低阈值 = 下界 + 向下取整(0.35×可用范围)
高阈值 = 下界 + 向下取整(0.65×可用范围)
```

对已接受的观察值保证“松开最大值＋保护值＜低阈值＜高阈值＜按下最小值－保护值”。这是项目筛选条件，不是高斯误码率保证，方差、极值和相关性仍受工作环境影响。须重复[实物干扰矩阵](interference.zh-CN.md#实物干扰矩阵)，充电、射频活动或完整外壳下分布重叠即不通过。
