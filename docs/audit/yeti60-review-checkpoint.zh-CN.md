# YETI60 全面复查阶段记录

[英文](yeti60-review-checkpoint.md) | 简体中文

按用户要求保存当前进展；这不是已经完成的装配审查或生产批准。

## 已完成

- 确认现有 STM32 主机测试不能单独验证当前 nRF52840 设计。
- 新增绑定当前 nRF 引脚的可移植控制核心，ASan/UBSan 主机模拟通过。覆盖全部 75 个扫描位置和电源／HID 控制场景，实际外设与协议栈仍为模拟接口。
- 按 [Nordic USB PHY 说明](https://devzone.nordicsemi.com/f/nordic-q-a/94955/resistors-for-d-and-d-)，将 R30/R31 从 27 Ω 改为 0 Ω；同步原理图、PCB、冻结封装、生成器及网表。
- 新增 ADC/GPIO 功能检查及铜线连接长度的保守估算。U6 第二颗输出电容与反馈连接仍绕行约 29–30 mm，充电器输入／电池电容路径也待处理。DRC 导通不等于电源布局已经合格。
- 电感侧直线段加宽至 0.35 mm；受过孔间距限制的斜线及芯片引出保留 0.2 mm。
- 开始将公开名称统一为 **YETI60**，文档迁移为英文默认、中文并行；保留上游署名和技术兼容标识。

## 提交后继续

- 优化被现有铜线阻挡的局部电源路径，再检查原生 DRC 和全部实际引脚连接。
- 注册真实 FELK60 垫片／定位板结构，在明确 Z 范围内检查 PCB、元件和壳体间隙。
- 检查候选电池空间。目前未选择电池，保护板、NTC、绝缘、膨胀余量及走线仍是要求。
- 按同一组检查坐标生成装配与爆炸渲染图，并明确示意元件。
- 完成项目文档英中同步，并刷新当前源文件的渲染。此前 PCB 单板渲染对应旧提交。
