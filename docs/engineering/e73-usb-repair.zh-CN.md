# E73 USB 修补阶段记录

**这是独立、尚未放行的候选方案。** 当前选用的 E73 主板、打样压缩包、固件及装配说明尚未被替换。[E73 整体审查](../audit/e73-review.zh-CN.md)仍然暂停放行。现有 UDB-C-JSH C5 子板保持不变。

候选包含真实的 [KiCad 工程](../../hardware/e73-usb-repair/EC60-nRF52840.kicad_pro)、完整五张原理图、冻结封装、导出网表及[可重放规格](../../hardware/e73-usb-repair-spec.json)。必须运行 E73 自身的检查，不能继承 Raytac 的验收结论。

## 电路改动

原 E73 板内 USB 路径约 255 mm，主板保护器件存在长支线。候选移除 D1、R30、R31，在模组旁新增四针 J4；通过 J5 和原 J1 将输入电源送回左侧电路。检查会独立核实 C5 的实际保护通道和两个保护接地端。移除主板 D1 本身不能证明防护有效。

| 连接 | 候选分配 |
|---|---|
| C5 J2.1，VBUS | J4.1，USB_FEED |
| C5 J2.2，DN | J4.2，USB_DM → E73 U1.29 |
| C5 J2.3，DP | J4.3，USB_DP → E73 U1.31 |
| C5 J2.4，GND | J4.4，GND |
| J5.1，USB_FEED | J1.1，VBUS，原左侧电源输入 |
| J5.2，GND | J1.4，GND |
| J1.2／J1.3 | 故意留空，线束不要装这两个端子 |

J4 位于 PCB **(346.1, 110.7) mm、90°**，朝 PCB X 减小方向侧向插拔，避免仅靠前移压缩前壁空间。J5 位于 **(335.5, 117.5) mm、0°**。C32 仅沿 X 移动 **0.3 mm**，保留原接地扇出，重布附近 USB_5V 连接。另移除 ROW_DRV4 上方冗余回路及其闲置连接点与支线，RESET_N 绕过 J4 固定焊盘；逻辑节点及 MCU 引脚分配不变。COL14 现从内层二绕开 USB 参考区域，保留感应焊盘且未新增过孔；USB_FEED 在局部使用内层一，向左远离接口后才进入内层二，避免切开数据参考面。规格文件逐项记录被替换控制铜箔的 UUID。

E73 的 43 个焊盘、感应焊盘、板框及安装孔位置保持一致。数据线为 0.3 mm 底层走线，没有数据过孔。新增 USB_FEED 路径／窄颈为 0.25 mm，采用普通 0.5／0.3 mm 通孔；完整压降、电流及温升验收仍未完成。

## 原生证据及边界

[原生检查报告](../../hardware/e73-usb-repair/audit/native-check.json)记录：严格 DRC 零错误、零未连接、原理图与 PCB 一致性零错误，**266 组信号／电源连接及 143 组接地连接全部连通**。按实际接触提取的两路板内 USB 中心线约 **9.96919 mm**，差值小于 **0.000002 mm**。这些是几何量，不是电气时延、阻抗或眼图结果，不包含 C5、线束及模组内部线路。

仍有 102 项原有虚拟庭院警告。原有非模组贴片焊盘与通孔重叠会在报告中逐项列出，吸锡及制造审查仍未放行。没有新增焊盘内过孔、模组焊盘内过孔、盲埋孔、填孔或盖铜工艺。检查保留原工程规则，在临时副本中启用被忽略的类别。

[故障测试](../../tests/audit/test_e73_usb_repair.py)针对真实候选注入：电源器件／层级网表缺失、数据针脚接反、USB 断线、E73 焊盘位移、原控制网络被改变、新增模组焊盘内过孔、错误恢复 J1 数据线，以及 C5 保护通道／接地缺失。[测试结果](../../hardware/e73-usb-repair/audit/fault-tests.json)不等于实物验收。

[参考面及局部模型阶段记录](e73-usb-return.zh-CN.md)检查完整原生数据铜箔、独立接地连通、实际修补前回归／故障案例，以及 J4、J5、C32 原生 STEP 焊接落点。这些配套报告补充原生检查阶段没有评定的项目。

## 材料差异

审阅这个候选时，使用它自身的[库存抵扣采购表](../../hardware/e73-usb-repair/mainboard-purchase.zh-CN.csv)。正式主板材料表对应另一块 PCB。

候选采购表已加入[局部匹配度规格](e73-usb-local-fit.zh-CN.md)规定的 J2/J4/J5/C32 安装高度及本体／焊接位置限值；这四个位置仅核对封装尺寸还不够。库存分配仍为计划使用 8 只、补购 67 只，共 75 只装板元件。

| 改动 | 每块候选主板数量 |
|---|---:|
| J2 从 PH 三针改为 JST SM03B-SRSS-TB(LF)(SN)、SH 三针 | 替换 1 只 |
| 移除 D1，PRTR5V0U2X／SOT-143 | 1 |
| 移除 R30／R31，0 Ω／0402 | 2 |
| 新增 J4，JST SM04B-SRSS-TB(LF)(SN)，SH 1.0 mm 侧插四针 | 1 |
| 新增 J5，JST SM02B-SRSS-TB(LF)(SN)，SH 1.0 mm 侧插两针 | 1 |

候选主板共 **75 个实装元件：计划使用库存 8 个，采购 67 个**。不包含电池、C5、对插胶壳、端子、线材和机械件。[SH 三针电池接口](e73-battery-service.zh-CN.md)已明确其胶壳和端子；裁线长度、理线件和完整带线装配图仍需一起定稿。原库存工作簿没有修改或上传。

## 复现

在仓库根目录使用 KiCad 自带的 Python 执行：

```sh
python scripts/build_e73_usb_repair.py
python scripts/check_e73_usb_repair.py
python tests/audit/test_e73_usb_repair.py
python scripts/export_e73_usb_ground.py
```

生成器核对源 PCB 哈希、复制完整层级原理图并重新填铜；若保留铜箔被自动改到其他网络，会直接报错。清单记录源文件及候选库、原理图、网表、采购表的哈希。接地导出器只读实际填充多边形，不修改 PCB；单独完成导出不代表回流验收通过。

尚需完成：线束／模组回流和完整 USB 信号完整性验收、完整插头退出和公差包络、九根导线的线束与维修运动、带线电池检修、左侧电源布局和热／封装检查、原生三维模型闭合、配套固件及校准标识、新制造文件，以及供应商和实物测试。**不要按已验收主板下单，也不要将正式方案现有固件或制造包当成此候选的配套发布。**
