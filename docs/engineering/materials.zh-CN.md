# YETI60 材料及采购要求

P1 阶段，2026-10-28。数量均为单把键盘净用量，不含备件。这是工程样机采购计划，标为候选、尺寸未确认的项目不能直接作为批准下单清单。电子材料以当前原理图为准，不沿用历史 EC60 材料表。

## 电子材料

执行 `python3 scripts/export_yeti60_bom.py` 可重新生成[主板分组材料表](../../hardware/bom/mainboard.zh-CN.csv)：**74 个实际焊装元件**，JP1 默认不装。电极、安装孔和 SWD 焊盘不是采购器件。R16／R17 已设增益 101，JP1 不能直接装零欧姆短接。PCB 包含 74 个可选布局电极位置，本次 HHKB 定位板只安装 **60 套按键机构**。J3 是六个探针焊盘，不是焊接排针。

| 总成 | 数量 | 要求 |
|---|---:|---|
| 主板 PCB | 1 | 当前 EC60-nRF52840 源文件；四层、成品 1.59 mm；按制板要求采用非对称 HDI 叠层及填孔盖铜 |
| 主板焊装元件 | 74 | 分组材料表列出数值、位号、封装、指定／候选型号及待确认项目 |
| USB 子板 | 1 块成品 | Unified Daughterboard C5 JSH，锁定提交 `2b6c52a`；[上游材料表](../../hardware/usb-daughterboard/upstream/production/UDB-C-JSH_5.0_bom.csv)有 7 个焊装元件，购买成品时不要重复计入散件 |
| USB 内部线束 | 1 | 暂按出线口间 150 mm；四芯、两端 SH 兼容插壳；电气直通：1→1 为 VBUS、2→2 为 D−、3→3 为 D+、4→4 为地；插头和弯折路径仍待验收 |
| 电池包 | 二选一，共 1 | 基准为定制 200 mAh、完整最大包络 50×20×2.9 mm；下挖底壳选项另行评估。单节 4.2 V 充电终止电压、独立充电温度保护、第三线 10k NTC；PHR-3：1 正极、2 负极、3 温度线 |
| USB-C 数据线 | 1 | 主机外接数据线，不能用仅充电线 |

主板 J1 继承了 1.0T-4P 供方标识。JST SM04B-SRSS-TB 是名义接口相符的候选，下单前须按[JST SH 图纸](https://www.jst-mfg.com/product/pdf/eng/eSH.pdf)复核固定焊盘和插接方向。J2 为 S3B-PH-SM4-TB，参见[PH 系列图纸](https://www.jst-mfg.com/product/pdf/eng/ePH.pdf)。连接器系列名不能保证线序正确。阻容具体型号、偏压下有效容量、保险丝动作特性和指示灯尚未完成供方确认，材料表已明确标注。

## 工具及装配放行

需要 SWD 调试器和自定义 J3 探针治具、逐线测通及测极性的万用表、小扭矩工具、卡尺，以及操作 SW100 的绝缘工具。本方案不需要逐键二极管、MX 热插拔座或第二颗主控。数量不代表库存或价格保证。

FELK60 提供定位板及胶棉安装依据。已查阅提交 `64db818` 的 [DELTA OMEGA 材料表](https://github.com/wZuck/delta-omega/blob/main/docs/BOM.md)，参考其机械／电子分项及键帽包络说明方式；其 MX 轴、XIAO 主控及双电池不能直接替换本项目材料。[PH60 Rev.3](https://github.com/ph-design/PH60)的可拆电池托盘和较大电池空间可供底壳下挖方案参考，但不同的 FDM 外壳、PCB 和固件不能证明 YETI60 的装配或续航。
