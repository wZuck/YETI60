# 默认单电芯电池和底壳下挖

P2 默认采用 **YETI60-BAT-1600-1S** 定制保护电池包，以 Honcell HCP404074 为电芯参考，完整包络为 **85×43×4.8 mm**。凹槽已加入正式[底壳 STEP](../../mechanical/generated/yeti60-bottom.step)，只保留一个默认底壳，FELK60 外部尺寸保持不变。USB 子板继续使用 C5 JSH。

它是在下述目录和网格条件中找到的最大候选，不代表全市场或连续位置的绝对最大值；完整电池包仍需供应商签图。

## 筛选方法和数据来源

[目录快照](../../hardware/bom/cell-catalog.json)包含 2026-10-28 从 [Honcell 表格](https://www.honcell.com/lithium-battery/cells/hcp-lipo-battery-cells/1316)取得的 249 个型号，以及 [Epec 表格](https://www.epectec.com/batteries/lithium-prismatic-cells.html)的 402 个 3.7 V 型号，不代表库存或报价。保留原始数值，包括 HCP256371 可疑的 25 mm 厚度，不能按型号自行改为 2.5 mm。

`screen_yeti60_batteries.py` 对至少 1000 mAh 的条目测试 0°／90° 两种方向、1 mm 位置网格和 −4.6／−5.5／−6／−8 mm 四种包顶高度。初筛在电芯长、宽、厚上分别增加 10、2、0.8 mm，预留极耳、保护板、包覆和增长空间；保护子板／嵌件区域、外壳螺钉区、元件外包络加 0.5 mm 和电池 XY ±0.4 mm 余量，要求扣除 0.3 mm 后至少保留 3 mm 壁厚。见[筛选报告](../audit/yeti60-cell-screening.json)。更细的位置、其他旋转角、组包结构和目录可能改变结果。

| 找到的候选 | 发布容量 | 筛选结果 |
|---|---:|---|
| Honcell HCP404074 | 独立规格书最低 1600 mAh | 最大候选；向上取整后的完整包络另做精确实体检查 |
| Epec 502699 | 目录值 1450 mAh | 较小容量的几何候选，未单独完成电芯验收 |
| Epec 453969 | 目录值 1360 mAh | 较小容量的几何候选，未单独完成电芯验收 |

[HCP404074 原厂独立规格 PDF](https://www.honcell.com/Public/Uploads/uploadfile/files/20240401/DATASHEETHCP4040743.7V1600mAhCELL2024.pdf)第 1–2 页规定：0.2C、23±2°C 下最低 1600／典型 1620 mAh，标称 3.7 V，充电 4.2 V，放电截止 3.0 V；本体交付最大 74.5×40.5×4.0 mm，循环后厚度最大 4.3 mm；长度不含 6±1 mm 极耳。初筛完整包络 84.5×42.5×4.8 mm 向上取整为 85×43×4.8 mm。这是工程组包预算，不是原厂成品签图。

**原厂资料存在矛盾：**充电行将 0.2C 写为 270 mA、1C 写为 1350 mA，与 1600 mAh 容量不一致。明确写出的条件是 0…45°C 下 270 mA、15…45°C 下 1350 mA。不能自行改成 320／1600 mA，也不能用参考充电曲线承诺充满时间。下单前须由供方书面更正或确认电流、容量测试及允许的充电电压误差。

## 默认方案的精确几何

| 项目 | 默认 P2 数值 |
|---|---|
| 完整电池包 | 85×43×4.8 mm，含保护板、NTC、折叠极耳、包覆及循环后增长 |
| 电池坐标 | X 228.5…313.5；Y −149…−106；Z −9.4…−4.6 mm |
| 凹槽坐标 | X 227.5…314.5；Y −150…−105 mm；圆角半径 1 mm |
| 槽底 | z=−9.60 mm；原局部内底 −5.91；下挖深度 3.69 mm |
| 去料体积 | 14443.182 mm³，即 14.443 cm³ |
| 最小法向壁厚 | 3.958500 mm；扣除 0.30 mm 后为 **3.658500 mm** |
| 电池到螺钉头名义间隙 | 0.700 mm |
| 槽底固定／间隙预算 | 0.200 mm，包含胶带和绝缘厚度 |
| 电池与壳体重叠 | 名义包络及 XY ±0.40 mm 扩张包络均为零 |
| 元件／受保护嵌件区域 | 检查的几何中无碰撞 |
| 扩张电池包的最小元件间隙 | 到 D2 为 0.555 mm；包含 XY ±0.40 mm 后仍超过 0.50 mm 要求 |
| 外壳合并包围尺寸 | 325.700×125.200×31.190 mm，无缩放 |

对覆盖整个新槽底的保守矩形与原始 7° 外底平面计算精确实体最小距离，不依赖少量采样点。原外底平面法向为 `n`，参考点为 `p`：

```text
z_外底(x,y) = pz − [nx(x−px)+ny(y−py)]/nz
法向壁厚 = (z_槽底 − z_外底) × cos(7°)
剩余壁厚 = min(法向壁厚) − 0.30 mm
```

正式底壳必须保持一个有效实体、原外部包围坐标不变，且切削体内部不残留材料；名义及扩张电池包络均与上下壳检查。0.70 mm 螺钉间隙的示例预算为 `0.70−0.15(槽底)−0.05(固定层)−0.15(PCB 堆叠)−0.10(螺钉头)=0.25 mm`，均为制造要求，非实测公差。3 mm 壁厚是几何标准，不是树脂结构强度认证。

## 电气和采购条件

P2 保留 BQ24074，R40=2.21k、R55=69.8k、R56=1.82k，均为 1%；主机接受 USB 配置后才启用 USB500。见[电流、计时、终止电流和续航计算](power-budget.zh-CN.md)。电池包必须具备独立断充温度保护，保证实际电芯允许充电窗口落在 **15…43°C** 内，目标 18…40°C，计入全部传感器和保护芯片误差；另提供第三线 10k 103AT-2 NTC。普通只做过压过流保护的保护板或两线软包不能等效替代。J2／PHR-3 自定义线序：1 电池正极，2 电池负极，3 NTC 接负极。

供方须签署完整尺寸、出线／弯折、保护阈值、独立温度断充、NTC 贴合、电流限制和容量。软包须绝缘固定，不得受挤压；固定结构须满足 0.2 mm 槽底预算。不能将旧小电池充电配置用于该电池，也不能用 P2 充电器给旧小电池充电。

FELK60 提供外形和定位板基准；`64db818` 的 DELTA OMEGA 参考材料表中电池／绝缘／紧固件分列方式；[PH60 Rev.3](https://github.com/ph-design/PH60)参考专用电池空间设计思路，其他项目的包络不能证明本项目容量。树脂蠕变、跌落、嵌件抗拔、完整线束可维修性、供方组包及充到终止电流仍需实物验收。目前没有样机，信号干扰分析按用户要求延后。
