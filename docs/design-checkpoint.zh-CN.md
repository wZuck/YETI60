# 阶段性设计记录

本次是工程中间提交，尚非制造发布。当前没有实物，下一阶段范围为完成设计及可构建固件。

- 普通版和 USB 串口校准版 ARM 固件已由完全锁定版本的 ZMK／Zephyr 清单构建。目标审计报告记录产物哈希、完整 Intel HEX 检查与设置分区保护。USB／BLE HID、配对和主机切换由 ZMK 提供。实际枚举、配对和静电容校准尚未实测。
- 不移动感应电极、元件、板框或安装孔中心，缩短电源局部线路。七个 0.40／0.20 mm 背面微盲孔连接 B.Cu 与 In2.Cu，严格 DRC 为零错误、零断线。上层感应介质保持 0.20 mm，下层激光介质为 0.15 mm，芯板为 1.115 mm，成品厚度仍为 1.59 mm。需要合格的 HDI 工艺、填充整平微盲孔、化金，以及另行规定的 U1 通孔填充盖铜。
- 树脂外壳派生实体增加冷粘嵌件座和底部开关检修孔，外部包围坐标逐项不变。4.6 mm 装配间距采用规定的 M2／M1.6 转接支柱及绝缘件；实际 Topre 结构仍需首件验收。
- 定制 200 mAh 电池包预留完整 50×20×2.9 mm 包络，包含保护电路、NTC、包覆及增长余量。要求独立充电温度保护及供应商签图，尚非已批准采购的现货电池。
- 后侧子板锁定为 Unified Daughterboard C5 JSH。原生 PCB 检查核对信号顺序、输入保险丝及两个独立的 5.1 kΩ CC 下拉。

后续工作：线束／插头及紧固件的完整 CAD 碰撞和公差检查、制造图纸、审计证据集成、文档同步及 PCB／装配图重新渲染。现有渲染清单与此前完整集成／结果报告不能证明本阶段设计。信号／射频分析按用户要求继续暂缓。
